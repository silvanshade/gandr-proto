# Status

The crate is slice 3 of the minimal certified kernel (`docs/gandr/spec/kernel-boundary.md` §8), stages B2.1 and B2.2: the **S1 pure polarized core** — term/type language, declaration vocabulary, environment + choke point, checker, and the C5-quarantined conversion (B2.1) — plus the **K5 export writer and validating reader** (B2.2) — complete and green.
Stage B2.3 landed the **kernel-native C5 goldens** here (`tests/goldens.rs` — the levelled-universe and explicit-lift fixtures, authored directly in kernel-core terms and round-tripping byte-identically); the bridge itself and the S1-eligible corpus partition live in the consumer crates (`gandr-core-checker` `kernel_bridge`, `gandr-core-sequent`'s partition sweep) since the TCB wall forbids the kernel depending on them.
The fcw.8 spec components (B2.4) are the remaining B2 stage.
The B2.3 deep-drop obligation (a decoded-then-rejected deep DAG dropping without stack overflow, massive-term design §7 item 7) is discharged structurally by the D1(C) arena and witnessed by `tests/hardening.rs::deep_decoded_declaration_drop_is_total` (cited, not re-added).

The representation is the ratified **D1(C) per-environment append-only arena** (gandr-5t3, `docs/research/massive-term-design.md` §3; impl-models §2.1/§5.1(1)/§5.6 #5): every term/type node lives in one `TermArena` owned by the `Environment`, addressed by four typed `u32`-backed node ids (`ValueId`, `ComputationId`, `ValueTypeId`, `CompTypeId`).
This **eliminates** the recursive-ownership hazard family the owned `Box` trees had: node children are `Copy` ids, so the derived `Clone`/`Drop`/`PartialEq`/`Eq`/`Hash` are shallow and arena teardown is a flat `Vec` drop — the hand-written iterative `Drop`/`Clone` worklists (gandr-i3i) are **retired**, not maintained.
No cached-word slot is reserved yet (S2-deferred).

Implemented (B2.1, slice 3):

* **Term/type language** (`term`, `types`, `base`) — the closed, de-novo S1 CBPV vocabulary (K1): values (variable, constant reference, unit, integer/string/numeric literals, pair, sum injection, thunk, explicit lift), computations (lambda, application, return, bind, force, sum case), value types (base atom, unit, product, sum, thunk, universe, lift), computation types (`F` pure, arrow).
  Terms are nameless (de Bruijn), so α-equivalence is syntactic; no hole/mark/metavariable/annotation/effect-row/datatype constructor exists to be represented.
  Literal payloads are canonical (normalized) so syntactic equality tracks value equality.
  Node children are typed **arena ids** (`arena`), not owned `Box`es; leaf payloads (`Literal`, `Level`, de Bruijn/constant indices, `Side`, `BaseType`) stay inline.
  Because children are `Copy` ids, the derived `Clone`/`Drop`/`PartialEq`/`Eq`/`Hash` are shallow — no recursion on term depth — so the iterative worklist `Drop`/`Clone` the owned trees required are retired and an adversarial-depth arena tears down in a flat `Vec` drop.
  **Derived-equality caveat (audited):** the derived `PartialEq`/`Eq`/`Hash` compare **child ids**, not structural equality across arbitrarily-shared arenas (the kernel preserves sharing but never creates it, so two structurally-equal subterms need not share an id).
  Every use site is re-justified: `conv` compares only inline leaf payloads by derived equality (leaves have no id children); the export writer keys dedup on explicit content keys; the round-trip tests witness structural agreement by byte identity of the canonical re-encoding, not by node equality across arenas.
* **Levels** (`levels`) — the per-declaration `LevelContext`: prenex parameter scoping and the universe rule `U_l : U_m` iff `l < m`, decided by `check_universe_below`.
  With no landmark constraints declared this is exactly `gandr_kernel_strata::Level::lt` (the free oracle); with constraints declared it is landmark entailment under the admitted poset (`entails_lt`), which strata guarantees agrees with the free oracle on the empty poset.
  Admission of the landmark constraints is a consistency gate (a looping set is rejected).
* **Checker** (`check`) — the zero-inference (K2), bidirectional S1 checker: annotation-free introductions check against the declared type flowing down; eliminators and atoms synthesize; a mode switch converts.
  No term-into-type substitution is ever needed at S1 (no type former is indexed by a value term), so context types are closed and never shifted.
  Total on adversarial depth via a **defunctionalized machine** (an explicit goal register, produced register, heap frame stack, and explicit typing-context stack) — not a recursion-depth budget — so it meets the `docs/workflow/rust.md` "input recursion: none" discipline (gandr-98o); type formation and conversion are the two self-contained iterative walks the machine calls directly.
* **Conversion** (`conv`) — the C5-quarantined definitional equality, over arena ids.
  An **id-equality early-out** fires first (same id in the same arena ⇒ the same node ⇒ structurally equal — the trivially-sound Lean `is_eqp`-first / smalltt ptr-eq posture, impl-models §2.1, admitting no table into the TCB, C3 held); the structural walk then resolves each child through the arena's checked `get`, failing closed to `Distinct` on a dangling id.
  At S1 the checker's conversion is type-only and coincides with structural equality (canonical levels); it never descends into a term, so the "never evaluate a computation during conversion" quarantine holds **vacuously**.
  The value/computation term conversion (α-structural, no β) is present, quarantined, and unused by checking — the seed for term-indexed extensions.
  Every face is iterative over a heap worklist of `Copy` id pairs (total at any depth).
* **Environment + choke point** (`env`, `arena`, `decl`) — the append-only `Environment` owns the one `TermArena` and the admission log, with the single checked entry `add_decl -> Result<CheckedId, KernelError>`, the single warned bypass `add_decl_unchecked`, and the `#print axioms` audit (`audit -> AxiomReport`).
  A declaration's content is built into the arena by a `DeclarationBuilder` (`Environment::stage`) that records the **content-start** watermark; the finished `Declaration` holds root ids (`declared: ValueTypeId`; `body: ValueId` for `Def`).
  Admission enforces the ratified invariant — after `add_decl` returns (success or rejection) the arena holds exactly prior declarations' nodes plus, on success, this declaration's content; checker intermediates never persist — by a **two-mark truncation** (the Idris commit-on-success staging overlay, impl-models §1.4/§5.3): the checker's synthesized intermediates allocate past the content-end mark taken on entry, and the arena truncates to content-end on success (dropping intermediates, keeping content) or to content-start on rejection (dropping both).
  Constant references resolve against the admission log; a `CheckedId` is unforgeable outside the crate; one checked/unchecked bit, no trust lattice (K3).
* **Errors** (`error`) — the closed, honest `KernelError` vocabulary; level and universe failures carry the `gandr_kernel_strata` refutation evidence they rest on.
  There is deliberately no non-canonical-level variant: an in-memory `Level` is canonical by construction, so the "reject non-canonical input" obligation is discharged by construction here and re-armed at the decode boundary in B2.2.
  A type-carrying payload (the mismatch and shape-mismatch variants) owns a **self-contained `TermArena` snapshot** of the reachable closure of its root(s), reified before the choke point truncates the working arena — so a rejected declaration's diagnostic survives truncation and tears down flatly (the snapshot's children are `Copy` ids).
  The new fail-closed `ArenaFault` surfaces (never trusts) a dangling id — the K1 weakening the arena reintroduces, unreachable when minting and lookup are wired correctly.

Implemented (B2.2, slice 3):

* **Export writer/reader** (`export`) — the K5 re-checkable export at the ratified **v1 maximal-sharing subterm-table format** (kernel-boundary.md §5, E1–E6; `docs/research/massive-term-design.md` §4, §7).
  `write` serializes an `Environment` to self-contained, deterministic canonical bytes: a v1 version header, the reserved sections, then the admission-ordered declaration sequence — each segment a **subterm table** (a unified tagged node table over all four families, one frozen `NODE_*` byte per former in the §4.5 order `0x00..=0x16`) rather than an expanded tree.
  Sharing is **maximal under structural equality**, computed by the writer via a **content-keyed dedup** post-order intern pass (the encoded entry bytes are the content key; the bytes are a function of the _abstract_ environment, never of in-memory sharing — a `no_std` `BTreeMap`); the walk is sharing-aware, so re-encoding a decoded DAG is `O(entries)`.
  Each declaration carries its admission mark and `Axiom`s serialize as `Axiom`s (E6); the precomputed `rested_on` sets are not written (E3).
  `decode` is the validating streaming reader: it mints each entry into a fresh `TermArena` once (**decode retains sharing** — a table index referenced twice reuses one arena id, never expanding), validating per entry (a known `NODE_*` tag; each child index strictly earlier and polarity-correct by table lookup; `MAX_TABLE_ENTRIES` as entries accrue).
  The **amplification defence**: after the whole table, one forward scan computes memoized saturating `expanded_size` and rejects any declaration root over `MAX_EXPANDED_TERM_WORK` **before replay** — bounding the recursive checker's tree-expanded work over the shared DAG without touching the checker.
  Canonical form (E4) is a **sharing-aware whole-artifact re-encode-compare**: a non-maximally-shared (duplicate), mis-ordered, or dead-entry table, or a non-canonical level/literal, re-encodes differently and is rejected `Malformed{NonCanonical}`.
  `read` imports each declaration's content into a fresh environment arena (sharing-preserving) and replays through the choke point — reproducing the environment with audits recomputed (E2/E3/E6); `ReadError` holds the decode plane (`DecodeError`) and the re-admission plane (`KernelError`) distinct.
  **E5 is a real version bump to v1**: a v0 (`version = 0`) or any other version is refused `UnsupportedVersion{found}`, exercising the refusal machinery against a real predecessor (the old v0 goldens are repurposed as refusal fixtures).
  The ratified budget constants (D3-tunable at B2.3): `MAX_EXPANDED_TERM_WORK = 1 << 24`, `MAX_TABLE_ENTRIES = 1 << 20`, `MAX_DECODED_LEVEL_OFFSET = 4096` (unchanged).
  All seven ratified reservations carry over format-plane only at v1: the R1 reserved declaration-kind tags (rejected distinctly), the R2 structured name pinned empty, the four R3 per-`Def` annotation slots pinned empty, and the R4 reserved minted-atom table pinned empty.

Tests are green under `mise run cargo:nextest`: per-module unit goldens (each checker rule, each error arm, the audit closure, the universe rule and its irreflexivity, landmark admission both ways, and the conversion id-equality early-out), plus `tests/conversion.rs` (reflexivity/symmetry/separation property differentials over generated specs materialized into an arena), `tests/checker.rs` (the kernel-native golden corpus of well-typed and ill-typed declarations, plus a totality-and-determinism property over arbitrary bodies), `tests/export.rs` (the round-trip, determinism, and rejection-totality differentials: `read(write(env))` reproduces declarations, marks, and recomputed audits; truncation at every prefix and arbitrary random bytes always return; the reserved kinds/slots, an unknown version, and a non-canonical level/literal encoding each reject), `tests/hardening.rs` (the adversarial-depth totality suite: ~1M-deep term/type arenas tear down, a decoded deep declaration and a deep reified-snapshot error payload drop, inside small-stack threads without overflow, and the defunctionalized checker admits a ~200k-deep pair and bind definition where recursive descent would overflow), and `tests/goldens.rs` (the B2.3 kernel-native C5 goldens: levelled-universe and explicit-lift declarations admit and round-trip byte-identically).
The arena-independent **spec** trees and an **iterative** (no-input-recursion) materializer live in the shared `tests/common/mod.rs`, since a term now only exists as ids in an arena.

## Design decisions recorded for review

* **Defunctionalized checker, no depth budget (gandr-98o).** The checker is a **defunctionalized adversarial-depth machine** ([`check::run`]): one goal register / produced register / heap frame stack / explicit typing-context stack replaces the six formerly mutually recursive methods, and the module docs carry a correspondence table (each old recursive arm ↔ one goal push plus at most one continuation frame) so the reviewer can walk the translation.
  Totality on adversarial depth is now structural — no recursion, so no stack to overflow, and no `Depth::LIMIT`/`DepthLimitExceeded` budget (both removed).
  This meets the `docs/workflow/rust.md` "input recursion: none" discipline for the kernel checker.
  Type formation (`type_level`) is a second self-contained iterative walk the machine calls directly, exactly as it calls the already-iterative conversion; the context is an explicit `Vec` of `ValueTypeId` slots with scope-exit frames, and slot lookup is a `Copy`.
  Under D1(C) the goal/produced/frame stacks and context slots are `Copy` ids: the former `Held` `Borrowed`/`Owned` split and its clone-on-lookup **dissolve** (an expected type is one id, propagated into both `case` branches with no clone), and eliminating a type former is a read of its child ids (no placeholder-swap, no E0509 interlock); synthesized types are minted into the arena as intermediates the choke point truncates after the verdict.
  The produced-register projections are **fail-closed** (`KernelError::CheckerRegisterFault`): a goal↔frame polarity mismatch — unreachable when the correspondence table is wired correctly — surfaces as a rejection rather than a fabricated type, so the machine's wiring is defense-in-depth over soundness, never a soundness assumption (coordinator review hardening; the `LevelOracleFault` surfaced-not-trusted posture applied to the machine's own registers).
  The kernel-vs-`gandr-core-checker` corpus differential stays green on its existing (bounded) domain; adversarial-depth inputs are excluded from that differential by design — the untrusted recursive reference keeps its own budget, so divergence there is deliberate, and `gandr-core-checker` is left unchanged.
  Deviation from the dispatch proposal (recorded for review): type formation is a **direct** iterative call rather than a goal in the term machine, because its `value_type_level`/`comp_type_level` recursion is a self-contained cluster (like conversion) — folding it into the term machine would force the `Lift` synthesis to compute the level of an owned, just-synthesized type through the goal stack, which the direct call avoids cleanly.
* **Lift is a value term, not implicit cumulativity.** `Value::Lift { target, body }` explicitly inhabits `ValueType::Lift { inner, target }` when the inner type's level is strictly below `target` — so a bare `body : A` never inhabits `Lift A target` on its own.
  This is the clean stratified realization of "explicit lift terms, no implicit cumulativity"; the spec's phrasing ("lift terms") is honoured as a value former plus its type former.
* **Declarations are value-polarity at the boundary.** A `Def` pairs a declared value type with a value body; a computation definition enters as a thunk (`U C`, body `thunk …`) and is used via `force`.
  This keeps `add_decl` single-polarity with no polarity-mismatch error.
* **A `Value::Constant` reference form** (a reference to a prior admitted declaration by admission position) was added beyond the coordinator's terse S1 value stock, because the append-only environment and its transitive `#print axioms` audit structurally require cross-declaration references.
  It is the only representable way an axiom can be "rested on".
* **Base-type atoms are `{ Integer, String, Numeric }`** — the three the S1 literal stock (`int/str/num`) names, taken as a closed, rigid set.
  Literal payloads are inert to checking at S1 (no type embeds a value term); the exact numeric-literal grammar is a v0 placeholder.
* **D1(C) per-environment arena, retiring the gandr-i3i worklists (gandr-5t3).** The owned `Box`-tree representation forced hand-written iterative `Drop`/`Clone` worklists into the TCB to stay total on adversarial depth (export decode builds a deep tree from bytes; every checker rejection path drops it).
  The arena **eliminates** that hazard family rather than managing it: node children are `Copy` ids into one `TermArena`, so the derived `Clone`/`Drop`/`PartialEq`/`Eq`/`Hash` are shallow, arena teardown is a flat `Vec` drop, and the manual `Drop`/`Clone` impls, their placeholders and `clone_*` walks, and the checker's `mem::replace` take-helpers are all removed.
  Ids are minted **only** by arena constructors over already-allocated children (a child id always resolves and is strictly less than its parent — the same strictly-earlier invariant the export table relies on), lookup is a checked `get` returning `Option` (never indexing), and each declaration lives in the one environment arena — the mitigations for the honest **K1 weakening** (an out-of-range or cross-arena id is now representable) which fails closed to `ArenaFault`/`Distinct`.
  The admission-watermark discipline (two-mark truncation; env bullet above) keeps checker intermediates from persisting, and type-carrying error payloads carry a reified snapshot so they survive truncation.
  Alternatives recorded in `docs/research/massive-term-design.md` §3.1: (A) `Box` trees (forecloses decode-retains-sharing) and (B) `Rc` children (manages, never eliminates, the recursive-ownership hazard and buys a second migration to the arena end-state) — both rejected by the 2026-07-20 owner re-cut.
  Deviation from the brief (recorded for review): **type-carrying error payloads own a `TermArena` snapshot** rather than an arena id, because the choke point truncates the working arena after the verdict — a bare id would dangle.
  The snapshot is reified iteratively (a resumable-frame post-order copy, total on any depth), so the `deep_error_payload_drop_is_total` witness holds structurally.
  No consumer reads the payload structurally (the mismatch accessors return ids into the snapshot arena), and the derived `PartialEq`/`Eq` on `KernelError` compare snapshot arenas positionally — used only by tests on leaf (payload-free) variants.

Export (B2.2) design decisions recorded for review:

* **v1 maximal-sharing subterm table with an expanded-work budget (gandr-5t3, massive-term design §4).** The v1 format shares subterms maximally under structural equality (a per-declaration-segmented tagged table over all four families, content-keyed dedup, decode-retains-sharing), which moves the billion-laughs attack from memory to **checker time** — a shared DAG the recursive S1 checker walks as a tree re-checks each shared subterm once per reference, up to exponential, and the depth-free defunctionalized machine bounds descent depth but not width-driven expansion.
  The reader's answer is an **expanded-work budget** (`MAX_EXPANDED_TERM_WORK`) enforced by a one-pass memoized saturating `expanded_size` scan **before replay**, plus a `MAX_TABLE_ENTRIES` cap enforced as entries accrue — the S1-priced defence that takes **no ptr-keyed trusted table into the TCB** (C3 held; the ptr-keyed checker memo is the deferred S2 successor, at which point the reader budget becomes defence-in-depth).
  The differential `a_repeated_diamond_dag_is_rejected_before_the_checker` confirms the rejection is on the decode plane, so the checker is never reached.
  The `NODE_*` byte assignment (`0x00..=0x16`, banded by family, §4.5 order) is a **frozen wire commitment under v1** (future formers extend it under a later version, which E5 makes safe).
  Alternatives rejected (design doc §12): per-family tables (forfeit dominant cross-declaration type sharing), non-maximal sharing (breaks E4 determinism), and amend-in-place versioning (wastes the E5 refusal against a real predecessor).
* **The transitive audit sets are recomputed, never exported (E3).** The precomputed `rested_on` sets are omitted from the bytes; the reader recomputes them by re-admitting each declaration through the choke point.
  Alternative: serialize the audit as a claim and re-validate it — rejected, because re-admission already recomputes it and shipping derived data invites trusting it (K4/E3).
* **Decode failure is a distinct type from typing failure.** `DecodeError` (format plane) is separate from `KernelError` (typing plane); `ReadError` unions the two for `read`.
  Alternative: widen `KernelError` with decode variants — rejected, because a malformed byte is not a typing judgment and the two planes must not blur.
* **A reserved declaration kind rejects distinctly (R1).** A reserved kind byte is `DecodeError::ReservedDeclarationKind`, not a generic unknown-tag rejection.
  Alternative: fold reserved kinds into the bad-tag arm — rejected as less honest and less diagnostic.
* **Structured names are a segment sequence pinned empty at v0 (R2).** The per-declaration name record is a segment count (zero at v0), never a flat dotted `M.l` string; a non-empty name is rejected, since S1 declarations are nameless and `add_decl` takes no name (a name could not round-trip).
  Alternative: omit the name field until names arrive — rejected, because R2 requires the structured shape present from birth.
* **Level decode is bounded by an offset cap.** Strata exposes no `O(1)` `var + offset` constructor, so a variable atom `x + o` is rebuilt through `o` applications of `succ`; a decode-time cap (`MAX_DECODED_LEVEL_OFFSET = 4096`) bounds that work — bounded work on adversarial input, the reader's totality posture.
  Consequence: a level whose _variable-atom_ offset meets the cap does not round-trip (implausible — real offsets are `0`/`1`; universe _constants_ are uncapped and `O(1)`).
  Alternative: an unbounded `succ` loop (rejected — not bounded work on adversarial input) or a fallible writer that refuses such levels (rejected — the task fixes the writer's return as `Vec<u8>`).
  The cap lifts when strata exposes an `O(1)` offset constructor (carry-note for a future strata slice; strata is out of B2.2 scope).
* **Canonical bytes are enforced by a sharing-aware whole-artifact re-encode-compare.** The decoder is tolerant (it normalizes through the constructors) and a single `encode(decode(bytes)) == bytes` check rejects every non-canonical encoding — a padded literal, a dominated level atom, an overlong varint, and (v1) a non-maximally-shared duplicate entry, a mis-ordered table, or a dead entry — as `DecodeError::Malformed { NonCanonical }`.
  The re-encoder is itself **sharing-aware** (a memoized DAG walk, `O(entries)`), so it is not an amplification vector; the expanded-work budget runs first and bounds it besides.
  Alternative: per-field canonical checks scattered through the decoder — rejected as more code with more room to leave a gap.
* **The writer reads the environment's admission log through a `pub(crate)` surface.** `Environment::admitted` (and the widened `Admission` visibility) expose the admission-ordered declarations and their marks to the same-crate writer without a public leak; the `to_digits`/`to_content` literal-payload accessors were added to `base` for the same reason.
  The byte-plumbing helpers (`ByteReader`, varints) traffic in `u8`/`usize` rather than nominal wrappers, a small deviation from the crate's primitive-wall discipline scoped to the codec interior; the domain surface (public API, tags-as-sites, error payloads) stays nominal.
  The arena's two internal index helpers (`id_index: usize -> u32`, `id_offset: u32 -> usize`) share that documented codec-interior deviation — raw index arithmetic between arena lengths and the `u32` an id wraps, the same category as the pre-existing `usize_to_u64`/`read_u32`/`read_usize` helpers.

**Pre-existing hazard (discovered gandr-5t3, undocumented before this pass):** the newly-materialized `mise run cargo:dylint` nightly pin (commit `7ec9da1`) now runs the project-local primitive-boundary rule that was previously not exercised, and it reports the codec-interior primitive signatures above (`decode`/`read`/`write` over `&[u8]`, `ByteReader` methods over `u8`/`bool`/`usize`, the varint/index helpers) as violations at HEAD as well as here — `cargo:dylint` exits non-zero for `gandr-kernel-core` at the branch base.
These are the documented codec-interior deviation, not new debt; `cargo:clippy`, `cargo:nextest`, and `treefmt:check` are green.
A dedicated pass to wrap the codec's byte/index interior (or to record a scoped `cargo:dylint` override) is a tracked follow-up.

Deliberately **not** here (kernel-boundary.md §7 S1 exclusions): effects/handlers, the control fragment, general recursion/natives, datatype declarations and description codes, `Sigma`/`Split`, `Path`/identity, `List`/`Record`/`With`, holes, marks, annotations, `dup`/`drop`.
The export format's seven ratified reservations are format-plane only and landed in B2.2 (`export`) — nothing is reserved inside the S1 types.

The crate is `#![no_std]` over `core`/`alloc`, depending only on `gandr-kernel-strata` — the design record's TCB dependency wall (kernel-boundary.md §2) in its sharpest form.
