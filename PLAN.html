3.1 · What the language is, per the live corpus

gandr is a dependently-typed language and proof system in Rust whose stated direction (wyrd@failed-refactor:docs/gandr/VISION.md §8; roadmap.md §1.4) is that every feature below is a facet of one fabric — a wheeled, polarity-sorted, graded nominal PROP with polygraphical data and a temporal-univalent dependent future. ADR-46 makes these decided directions with construction as the open research obligation. The honest register: shifts 4/5, the evidence layer, and univalent reflection "have essentially no runnable language code today" (VISION.md §8). The built surface is a much smaller core; the badges below mark documented build state.

Core calculus: CBPV + polarized System-L built core

The frozen source/typing calculus is call-by-push-value with a bidirectional checker and a derived defunctionalized typing machine, property-tested against a recursive checker (wyrd@failed-refactor:docs/gandr/spec/type-system.md rules + spec/core-ir-contract.md §§1-6 frozen shapes; ADR-1/28/31/32/38/39). Runtime is the A5.1 sequential CK evaluator — the frozen driver and differential oracle (pure spine + algebraic effects + delimited control); the A5.2 process-soup runtime is deferred.

Sitting beside CBPV as a second machine face is polarized System-L (λμμ̃), adopted as the machine-and-optimization IL (spec/proposal-sequent-kernel.md + -addendum-vdc.md; ADR-65). The load-bearing thesis (from the notes, §3.4 below): gandr's CEK machine already is a sequent machine in a costume — the cut is the machine step, Cont::Bind is µ̃. Evaluation strategy = polarity orientation on the µ/µ̃ cell (positive cuts fire CBV, negative CBN). As built: sequent L0 command face + static focusing; L1 partial (pure-spine checkpoint merged, zero-disagreement differential vs the CK oracle).

Grades / coeffects built

Semiring-graded thunks with a sealed 0/1/ω carrier (fin/leq/plus/times + dup/drop) (spec/type-system.md §2 + core-ir-contract.md §4; ADR-4/28). The grade/phase axis also carries gandr's erasure needs — erasure ≠ irrelevance (distinct axes; ADR-32). A gradual layer (Unknown + holes) exists, with subtyping reflexive-but-not-transitive once Unknown participates.

Unions / intersections, worlds, sessions adopted-unbuilt

Type-system extensions — ∪/∩, polymorphism, kinding, worlds — are decided design with no code (spec/type-system.md §§4-5, §9). Likewise sessions (binary/shared/multiparty; type-system.md §§6-8), which the notes reframe as linear, two-sided, typestate-indexed codata gated behind a codata MVP, where session duality = logical duality and communication = cut (theorem-shaped).

Module system (1ML) partially built

A 1ML-style module system is on record as decided design (spec/modules.md), and part of it is built — visible in the corpus and the proposed agda-deps gandr script (owner correction at PLAN review; the survey's blanket adopted-unbuilt verdict is stale here). Functors and first-class modules are not built yet — they are the B3 backbone work. Genuinely adopted-unbuilt neighbors: metaprogramming (phases, hygienic macros, elaborator reflection; spec/proposal-metaprogramming.md, ADR-19/20) and the pluggable solver interface (spec/proposal-solver-interface.md, ADR-16).

Effects & handlers + control built

Algebraic effects on the F connective — typing plus the A5.1 runtime (perform / deep handle) — are built (spec/effects-control-shell.md §1-2 + core-ir-contract.md §5; ADR-14/29/33/34), as are first-class control stacks with reset/shift (§2 + §6.3; ADR-25/29) and the POSIX shell DSL + headless host runtime (Part C; ADR-35/42). Divergence is treated as an effect (CBPV effect quarantine), part of the non-termination story in §3.4.

Parse / type pipeline partial

The normative parser is the PBG + melder push machine, end-to-end and tree-sitter-free (melder P1-P3, obligations/expected as first-class queries, merkle origin map; REPL/TUI/sans-io LSP) — tree-sitter's authority is retired, kept only as parity/editor tooling (spec/proposal-parser-interaction-core.md, as-built normative; proposal-surface-syntax.md amendment; ADR-70/73/75). The incremental pipeline is typing-only: as built there is no incremental parsing — reuse happens at the typing layer (spec/incremental-pipeline.md:3; ADR-10/17).

Dependent-types trajectory stage-1 core Live

Dependent types arrive by a staged levitation ladder (spec/proposal-levitation.md; ADR-67/81). Stage 0 (descriptions) is built; levitation stage-1 dependent core — a Type universe + Σ pair + decode is Live in the frozen core per ADR-81, together with the declared-data 1-cell MVP (ADR-80) and split-motive (ADR-82). Universe discipline is a judgmental level kernel {0,+1,max} with a Bezem–Coquand polytime oracle (spec/kernel-boundary.md; the governing kernel focus, ADR-77/78); surface keyword is Type, not Set.

Higher-dimensional rewriting + VDC further along than docs say

Owner correction at PLAN review: per the L-machine work stream, the higher-dimensional rewriting machinery is basically (or mostly) in place and what it needs is an end-to-end demonstration — i.e. the docs below understate build state, and B11 (HDR story) is a demo/integration phase more than a construction phase.

The fabric's data are laws as computed, inspectable IR — computads/polygraphs — with fusion realized as Squier completion on cut seams (user rule 2-cells → command rewrites; overlaps at a cut are critical pairs; fused rules carry tracelet 3-cell certificates). The shared internal language is a virtual double category (CFVDC / FVDblTT) (spec/proposal-vdc-reflection.md; ADR-68/69), whose F5 architecture is adopted-unbuilt, with four *-addendum-vdc.md deltas that are strictly additive to later stages (§3.2). The nominal PROP substrate is proposal-term-face.md / VISION.md §8 (ADR-41/46-A).

Identity & univalence direction rung U1 Live (partial)

Identity is a rung-1 Path/here/walk fragment with definitional walk-β and no K, no η (ADR-76/79), carrying a without-K negative witness in the test suite (spec/proposal-identity-univalence.md §2-4 + core-ir-contract.md §0). The committed name for the univalence direction is temporal univalence — staged, certificate-carrying (ADR-76) — deliberately avoiding the nLab "internal univalence" collision; the "temporal, not spatial" slogan is banned in the manual until a prediction lands. The remaining ADR-46 fabric — polygraph-data, erasible-evidence (phase-distinct evidence → non-dependent core, ADR-46-C), temporal-univalence beyond U1 — is decided-direction, unbuilt.

Built and running today (arbiter: core-ir-contract.md §0, verified current by BLAKE3): the CBPV checker + typing machine + A5.1 CK evaluator; value-model rungs 1-4 (strings/ints/numerics, covariant List, closed records with width/depth <:); grades; declared-data 1-cell MVP + levitation stage-1 core + split-motive; rung-1 identity; the PBG parser lane; sequent L0/partial-L1; levitation stage-0 + codata MVP on the description side; the gandr-kernel-levels oracle (slices 1-2); Wave-1 usability MVPs (attributes, interpreter FFI, functional record/list update, inspection-protocol wire crate); and an executable corpus of 82 cases (crates/gandr-corpus, ADR-52). Nearly everything else — the PROP fabric, polygraph data, sessions, worlds, modules, metaprogramming, backend, packages, pretty-printing, diagnostics Report v3 — is adopted-unbuilt or design-pass.

3.3 · The internal-univalence (iu) absorption

internal-univalence (iu) is gandr's companion Agda formalization — the "mathematics" side of the project (ADR-30: Agda is the sole proof vehicle). It is the metatheory backend of gandr's identity/univalence (temporal-univalence) program: 67 .agda modules under one permanent root Internal.*, carrying the CFVDC/doctrinal-carrier metatheory, the Squier/rewriting engine, coherence proofs, and the ua-base certification layer. "Absorbing iu" means inverting the vendoring — moving IU's source into gandr rather than pinning it as a submodule. The absorption decisions:

Namespace — keep Internal.* decided (iu-owner)

Internal.* is declared permanent (iu:docs/spec/ADR.md ADR-4, ADR-12 D3; bead iu-9r3): it names the method (internal to MLTT), is consumer-load-bearing (wyrd imports Internal.Graph etc. verbatim), and is out of scope even for the repo rename to "Temporal Univalence." "Absorb verbatim" ⇒ keep Internal.* and let the house root Gandr.* sit above it (today's wyrd layering). A re-root would touch 67 module headers and break the wyrd contract and the owner's decision — recommend: do not re-root.

Build — Agda 2.8.0, strict-root / holey-leaf stdlib direction needs a gandr ADR

Agda 2.8.0 pinned; kernel OPTIONS --safe --without-K --hidden-argument-puns, with --guardedness per-module only. One strict gate root Internal.Everything (imports every hole-free module), one declared holey leaf Internal.Polygraph.Coherence (gated separately, tolerating UnsolvedInteractionMetas), a separate Meta.* root. Two library lines (ADR-9): a dependency-free kernel and a reflection-tactics meta layer that admits stdlib. The owner's new direction — generally adopt agda-stdlib, renamed locally to house-style — contradicts iu ADR-2/ADR-9 and needs a gandr ADR that supersedes them; the mechanism already exists (wyrd's Gandr.Prelude re-exports vendored stdlib). Provision stdlib by local clone, not a nested submodule (a ~600 MB recursive-checkout hazard, iu-49f).

Coherator home — two parallel realizations live open frontier, not a finished proof

The headline question. The coherator now lives in two parallel homes, mirroring the groupoid/doctrinal split, and in both it is the project's live open frontier:

  • Groupoidal (original, landed with a located hole): the coh cell + Coh/CohCell/coh-total in iu:src/Internal/Polygraph/Complex.agda (the 𝔉 free complex), its ⟦coh⟧ interpretation in the deliberately-holey leaf iu:src/Internal/Polygraph/Coherence.agda (nothing imports it), routing through coherence-from-acyclicity — Squier's theorem internalized — over the engine in iu:src/Internal/Rewriting.agda(+Confluence). One located open obligation remains (the closing recursion; "the point is that it is open and exactly located").
  • VDC-shifted (newer, statement grade): iu:src/Internal/Doctrine/Complex.agda (𝔇ω) with VCoh/coh/VSquier, where Squier completion is named per level as an engine dependency, not interpreted inline: coherence-supply holds by construction (the coh constructor is the filler), while acyclicity (VAcyclicAt) is the genuine crux, supplied by an unbuilt tree-ARS kernel (the "T5 engine dependency — named here, never built"). Certification tower in iu:src/Internal/Doctrine/Certified.agda (∞VDC, UnitLayer).

Absorbing "the coherator" absorbs a live research frontier, not a closed proof — by design (the ADR-1 posture: "construction + a precisely-located open problem").

wyrd seam — invert the vendoring pin badly stale by design

gandr's current Agda face is wyrd@failed-refactor:metatheory/: a --safe --without-K Gandr.* signature tree (16 modules, zero postulates, uninhabited proof-target records) that consumes IU as a pinned git submodule, importing only the engine — Internal.Graph, Internal.Rewriting, Internal.Rewriting.Confluence (+Internal.Prelude for Gandr.Prop.*). The holey Coherence leaf is deliberately NOT imported. 3.5 · Nominal-automata groundwork (Σ-lifecycle)

Two Erlangen papers supply the decision-procedure technology for gandr's Σ-class — channels, capabilities, worlds, roles — i.e. the name allocation/deallocation lifecycle. Adoption status: decided-adopt a theory-nominal-automata crate layering on gandr-nominal (ADR-41's Atom/Gensym), folded into the build-out phases. The initially-documented site is the Σ-class (ADR-46 notes macro-hygiene and CMTT-Ψ keep their own machines), but the framing is deliberately not narrow (owner direction at PLAN review): this is substantially new, potentially performance- and capability-enabling technology, and a broader view has repeatedly transformed what the whole system can do — so adoption is evaluated opportunistically at each build-out stage beyond the planned sites. Fixpoint reasoning over names is already registered for this axis (K-11 Hausmann–Milius–Schröder, nominal μ-calculus with name allocation; K-12 Klin–Łełyk, μ-calculus with atoms).

The engineering trick is shared — one reduction template, not duplicated per model: (1) a name-dropping modification closes the literal language under α-equivalence (orbit blowup ≤ 2^degree); (2) S-restriction to a bounded name set; (3) delegate to a classical finite-alphabet NFA / NFTA where inclusion, emptiness, and determinization are standard. A nominal automaton is thus a finite handle whose decision problems delegate to classical automata. Complexity is parametrized by degree = number of concurrently-live names — the realistic session/shell regime — and everything is elementary: RNTA inclusion 2-EXPTIME (singly-exponential-parametrized in degree, Thm 6.3/6.6); NDA inclusion EXPSPACE (PSPACE-parametrized, Thm 5.12).

NDA — the standout: determinism

NDA's alphabet is literally malloc/free with interleaved, non-nested scopes. Its headline surprise: NDA can be determinized (Thm 8.14) — "quite unusual" for nominal automata, where deterministic models are normally strictly weaker. Explicit deallocation is exactly what buys it. This is the key property for gandr's runtime-monitoring use case (a forward monitor must be deterministic). Deallocation adds no expressivity (NDA ≡ RNNA under local freshness, Prop 5.11) — its value is determinism + a memory-safety discipline (disciplined words = free each resource as soon as it is dead, Def 4.1) + a Kleene-style regular-deallocation-expression algebra (Thm 7.19/7.20) usable as a Σ-protocol DSL.

RNTA — the session/term model

RNTA processes α-equivalence classes of trees carrying bound names (λ/π terms, XML-like data). Under global/branchwise freshness it generalizes session automata — so a projected local type / session protocol is representable as an RNTA and protocol refinement checks as language inclusion. A state q(a₁,…,aₙ) = control point + set of live endpoint atoms — the exact analogue of a gandr Σ-state. Redirection = endpoint delegation = the nominal renaming action, which is why the Σ-lifecycle wants a nominal substrate (BTreeSet<Atom> support with native ⊆).

Substrate needs align with what the corpus already plans: an order-theory layer (support as a ⊆-poset; the term/word order for local-freshness downward closure) and a graph-theory layer (orbit-finite state sets + equivariant transition relations are labeled graphs; the classical back-end is reachability = emptiness, product/subset = inclusion, powerset = determinization) — matching gandr's planned gandr-graph and ADR-46's supported-sets representation.

Provenance boundaries the plan must keep clean.

  • Contradiction corrected against the primary source: wyrd-notes:archive/digest/props-successors-handoff.md claims "the 'RNTA' acronym is the dialogue's invention" — false; papers:LIPIcs.CONCUR.2024.35.pdf itself coins and uses "regular nominal tree automata (RNTA)."
  • "Runtime monitoring" and "POSIX modeling" are gandr-side framings, not paper claims: the papers own the models and decision procedures; the application mapping is design synthesis citing the gandr specs (effects-control-shell.md, typing-machine.md, VISION).
  • Emptiness is an inference, not a stated theorem in either paper (both center on inclusion, determinization, Kleene) — it follows from the finite-alphabet reduction.
  • Open-research gap: there is no tree-with-deallocation model in the literature. gandr's Σ is both tree-structured (session protocols) and dealloc-heavy — combining them is a construction obligation / potential publishable contribution, not something to assume exists.
